# sqltx

`sqltx` выполняет функцию в транзакции `database/sql`. Пакет использует только стандартную библиотеку.

```go
err := sqltx.Do(ctx, db, nil, func(tx *sql.Tx) error {
    _, err := tx.ExecContext(ctx, `UPDATE accounts SET active = $1 WHERE id = $2`, true, id)
    return err
})
```

`Value` также возвращает значение функции. Значение доступно вызывающему коду только после успешного commit; при любой ошибке возвращается нулевое значение типа. `ctx` и `opts` передаются в `db.BeginTx`; `nil` для `opts` означает настройки драйвера по умолчанию.

Например, счётчик попыток должен сохраниться и при отказе по лимиту. В таком случае callback возвращает решение как значение, а не как ошибку; отказ обрабатывается после успешного commit:

```go
denied, err := sqltx.Value(ctx, db, nil, func(tx *sql.Tx) (bool, error) {
    var attempts int
    err := tx.QueryRowContext(ctx, `UPDATE limits SET attempts = attempts + 1
        WHERE subject = $1 RETURNING attempts`, subject).Scan(&attempts)
    if err != nil {
        return false, err
    }
    return attempts > limit, nil
})
if err != nil {
    // Не удалось подтвердить сохранение счётчика.
} else if denied {
    // Лимит превышен; счётчик сохранён.
}
```

При ошибке начала транзакции функция не вызывается. При ошибке функции пакет пытается выполнить rollback и объединяет через `errors.Join` её ошибку с ошибкой rollback, которую сам получил, кроме `sql.ErrTxDone`. Например, при отмене контекста `database/sql` может уже выполнить rollback самостоятельно, и повторная попытка вернёт `sql.ErrTxDone`.

При панике callback пакет пытается выполнить rollback и не перехватывает исходную панику. Пакет также не перехватывает панику драйвера; паника во время rollback может заменить исходную. Ошибка commit возвращается вызывающему коду: её исход для базы может быть неоднозначным, успешный rollback не гарантирован и автоматического повтора нет.

Функция не должна вызывать `Commit` или `Rollback` самостоятельно либо выполнять внешние побочные действия, которые требуют успешного commit. Пакет не предоставляет вложенные транзакции, savepoints и повторы. Он не устраняет нехватку соединений пула: размер пула и порядок работы с транзакциями определяет вызывающий код.
